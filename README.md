# M/s Nabi Enterprises & M/s Jhimik Transport Agency
One self-contained `index.html` (HTML + CSS + JavaScript) plus photos in `assets/images/`. No build step.

## Upload to GitHub (repo EditorAnikAdhikary/MsNobiEnterprise, branch main)
1. Delete ALL old files in the repository.
2. Upload `index.html`, `README.md`, `.nojekyll` and the whole `assets` folder to the repository ROOT.
3. Settings > Pages > Deploy from a branch > main > / (root).
4. Open https://editoranikadhikary.github.io/MsNobiEnterprise/ (1-2 minutes).

Pages are sections of one document, reached with `#home`, `#about`, `#products`, `#product-cement`, `#jhimik-transport`, `#road-transportation`, `#gallery`, `#contact`, etc.
Images are referenced as `assets/images/<name>.jpg` (relative, lowercase, no leading slash).

Notes: images are AI-generated illustrations (418x235 px) and the site says so; the portrait placeholder is unused. The contact form has no backend. No email or map (unverified). Confirm phone numbers and address with the owner.
